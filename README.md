# COMP4122 2D roguelite combat plaformer

This is a game project for COMP4122 GAME DESIGN AND DEVELOPMENT

The source code will be released on different stage of the project

## Build

Requires **Godot 4.7**. Open the folder in the editor (or `godot --path .`).

## UI

All screens (title, options, in-run HUD, pause, game over), the shared theme and
the art pipeline are documented in [`UI/README.md`](UI/README.md).

```
godot --headless --path . tools/ui_flow_test.tscn   # UI smoke test
```
